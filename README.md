# 📝 Random Quote Generator

This is a simple web app that fetches and displays **random quotes** using the [Quotable API](https://api.quotable.io).  
Users can view inspirational quotes and share them directly on Twitter.

---

## 🚀 Features

- 📖 Get a new quote every time the page loads
- 🧠 Displays the quote text and author
- 🐦 "Tweet" button to share quotes on Twitter
- 🔗 Powered by the open [Quotable API](https://api.quotable.io)

---

## 🛠️ Technologies Used

- **HTML** – Page structure
- **CSS** – (Optional) Styling for layout
- **JavaScript** – API fetching and DOM manipulation

---

## 💻 How It Works

1. When the page loads, JavaScript makes a `fetch()` request to the `https://api.quotable.io/random` API.
2. It gets a random quote and updates the DOM with the quote content and author.
3. A Twitter share button opens a new window to post the quote.
